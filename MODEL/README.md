# S2S_Translation

This repository contains a small sequence-to-sequence translation project (local workspace import).

Files in this repo:

- `interface.html` — simple HTML interface for the translator
- `translator.html` — another HTML file related to the UI
- `main2.py` — main Python script for running the translator
- `model2.py` — model definitions / helper code

Quick start

1. Make sure you have Python installed (3.8+ recommended).
2. From the repository root run:

```
python main2.py
```
